# SolarX — Storefront demo

Interactive, static demo of the SolarX online shop, hosted on GitHub Pages.

**Live:** https://aurelajas.github.io/solarx-store-demo/

- Browse the catalogue, filter by category, open product pages, read the blog, try the savings calculator.
- Add to cart, sign in with **any email and password** (or `demo@customer.com` for a customer with order history), check out with a coupon (`WELCOME10`, `SOLAR50`), confirm a simulated card payment and download the invoice PDF.
- No backend: every request is answered in the browser from sample data. Changes are kept in your browser only — use **Demo → Reset demo data** to start over.

Admin panel demo: https://aurelajas.github.io/solarx-admin-demo/
